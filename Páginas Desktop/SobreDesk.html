Sobre Nós

Quem somos

Somos estudantes do curso de Informática para Internet do IFSP — Campus Caraguatatuba, desenvolvendo este projeto como parte do nosso Projeto Integrador (PIN). O Biomas do Brasil é uma plataforma web criada para apresentar informações sobre os ecossistemas brasileiros de forma acessível, interativa e responsiva.
